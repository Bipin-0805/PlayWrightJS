# PlaywrightJS

A classroom learning project for exploring browser automation with **Playwright and JavaScript**. This repository is updated daily as lessons, exercises, and examples are added.

## About the project

The goal is to learn Playwright step by step in a classroom setting. The project provides a place to keep daily practice and track progress while building skills in writing and running browser tests with JavaScript.

## What you’ll find here

- Daily classwork and learning exercises
- JavaScript examples for practicing Playwright
- A growing record of topics covered and skills learned

## Learning in progress

This is an active learning repository, so its contents may change as the class moves through new topics. Check back for daily updates.
